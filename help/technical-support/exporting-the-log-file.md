# Exportieren der Protokolldatei

Wenn Sie Unterstützung in Bezug auf Substance 3D Sampler benötigen, ist es immer gut, Ihre Protokolldatei freizugeben, da sie den Kontext Ihrer Computerkonfiguration angibt.

## Exportieren der Protokolldatei aus der Anwendung

Die Protokolldatei kann direkt von Substance3D Sampler exportiert werden, indem Sie im Menü **Hilfe** das Element **Protokolldatei exportieren** auswählen.

![](../assets/export-log.jpg)

## Die Protokolldatei wird manuell auf der Festplatte abgerufen.

Wenn Sie Substance 3D Sampler nicht starten können, können Sie die Protokolldatei manuell abrufen, indem Sie den folgenden Ordner verwenden:

Adobe-Version:

* **Windows**: C:\Users\** Benutzername**\AppData\Local\Adobe\Adobe Substance 3D Sampler\log.txt
* **Mac OS**: Macintosh > Benutzer > **Benutzername** > Library > Application Support > Adobe > Adobe Substance 3D Sampler > log.txt

Substance3D-Version:

* **Windows**: C:\Users\** Benutzername**\AppData\Local\Allegorithmic\Adobe Substance 3D Sampler\log.txt
* **Mac OS**: Macintosh > Benutzer > **Benutzername** > Library > Application Support > Allegorithmic > Adobe Substance 3D Sampler > log.txt
* **Linux**: /home/**Benutzername**/.local/share/Allegorithmic/Adobe Substance 3D Sampler/log.txt

>[!NOTE]
>
> Unter **Windows** ist &quot;AppData&quot; ein ausgeblendeter Ordner.\
> Auf **Mac OS** ist &quot;library&quot; ein ausgeblendeter Ordner.\
> Auf **Linux** ist &quot;.local&quot; ein ausgeblendeter Ordner.

## Anhängen Ihrer Protokolldatei an einen Forumbeitrag

Wenn Sie im Forum um Unterstützung bitten, ist eine Protokolldatei erforderlich. So hängen Sie eine Protokolldatei an Ihre Nachricht an:

1. Überprüfen Sie die Einstellung &quot;**Mit Datei verbinden**&quot;.
1. Klicken Sie auf die Schaltfläche &quot;**Datei auswählen**&quot; und suchen Sie Ihre Protokolldatei.
1. Klicken Sie auf &quot;**Beitrag**&quot;, wenn Ihre Nachricht bereit ist, Ihre Protokolldatei zu posten und hochzuladen.

![](../assets/attach-log-step-1.png)
