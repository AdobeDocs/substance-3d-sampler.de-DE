# Abbildung zum Material visueller Artefakte

Die Ergebnisse von <b>Bild zu Material (KI-gestützt)</b> können manchmal geändert werden (hauptsächlich falsche Farben).

Aktivieren oder deaktivieren Sie die *GPU-beschleunigten neuronalen Netzwerke* im Abschnitt <b> Machine Learning</b> der Voreinstellungen von Substance 3D Sampler, um das Problem zu beheben.
