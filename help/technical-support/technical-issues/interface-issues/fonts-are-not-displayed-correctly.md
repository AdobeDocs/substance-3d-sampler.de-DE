# Schriftarten werden nicht korrekt angezeigt

Wenn Sie sich in Windows 10 Enterprise befinden und die [Funktion nicht vertrauenswürdige Schriften blockieren](https://docs.microsoft.com/en-us/windows/security/threat-protection/block-untrusted-fonts-in-enterprise) verwenden, können Sie dieses [Tutorial](https://www.tenforums.com/tutorials/139148-exclude-specific-apps-untrusted-font-blocking-windows-10-a.html) befolgen, um Sampler von der Liste der nicht vertrauenswürdigen Apps zum Blockieren von Schriften auszuschließen.
