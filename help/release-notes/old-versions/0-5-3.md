# 0.5.3

Freigabedatum: **2019/03/19**

Hinzugefügt:

* Suchen Sie im Bedienfeld &quot;Ressourcen&quot; nach dem Materialnamen
* [UI] Klon Tool neue Benutzeroberfläche mit Visualisierung der Pinselgröße
* [UI] Ausgeblendete Phasen auswählen und löschen
* [UI] Neue Textfeld-Benutzeroberfläche
* [Help] Zugriff auf Websites von Substance Source, Substance share und Substance Academy
* [Inhalt] Neue Standard-Materialien mit Generatoren und Atlas
* [Inhalt] Aktualisierung von Bitmap zu Material
* [Inhalt] Dirt-Update
* [Inhalt] Rost-Update
* [Inhalt] Neuer Prägefilter
* [Inhalt] Neuer Stickereifilter
* [Inhalt] Neuer Erosionsfilter
* [Inhalt] Neuer Kiesgenerator
* [Inhalt] Neuer Malen-Filter
* [Inhalt] Neuer Filter &quot;Parkettmuster&quot;
* [Inhalt] Neuer Filter für Pflastermuster
* [Inhalt] Neuer Perforationsfilter
* [Inhalt] Neuer Splatter-Filter
* [Inhalt] Neuer Textilverschleißfilter
* [Inhalt] Neuer Transformieren Filter

Fest:

* [Viewport] Sphere Mesh mit Kachelung x2 auf X
* [Viewport] Absturz beim Laden Ihrer eigenen Umgebung
* [Viewport] Umgebungs-Map verwenden jetzt auch den Belichtungswert
* [Viewport] F Tastaturbefehl setzt den Winkel der Kamera nicht zurück
* [Exportieren] SBS Export funktioniert mit dem neuesten Substance Designer 2018.3.3
* [Exportieren] SBSAR-Export entspricht den gleichen Richtlinien wie Substance Source Materials
* [UI] Bildlaufleisten können gezogen werden
* Sonderzeichen werden für Ordner- und Dateipfade unterstützt
* Die Miniaturansicht wird neu generiert, wenn Sie Ihr Material speichern

Bekannte Probleme:

* Die Verwendung mehrerer Delighter in einem Material wird nicht empfohlen
* Delighter stürzt mit älteren NVIDIA-Treibern ab (weniger als 400.x)
* Der schnelle Wechsel der Sichtbarkeit einer Delighter-Bühne wirkt sich auf die Leistung aus
* Import von benutzerdefinierten Umgebungen kann schwarz werden
* TIF-Bilder werden im Bedienfeld &quot;Eigenschaften&quot; der Bildimportebene nicht angezeigt
* Koma oder Punkt können ignoriert werden, wenn Sie einen bestimmten Wert in einen Schieberegler eingeben
* Die Standardsammlung, in der gespeichert werden soll, kann leer sein
