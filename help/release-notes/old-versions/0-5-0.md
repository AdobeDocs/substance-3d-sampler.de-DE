# 0.5.0

Freigabedatum: **2019/02/28**

Hinzugefügt:

* [Ebenenstapel] Ebenenanordnung
* [Ebenenstapel] Löschen einer ausgeblendeten Ebene
* [Ebenenstapel] Importieren Sie ein Material direkt an der gewünschten Position.
* [Ebenenstapel] Material-Eingabe als neuer Filterparametertyp
* [Performance] Das Substance Engine-Budget ist dynamisch und verbessert die Performance.
* [Performance] Bessere OpenGL-Performance, insbesondere bei MacOS
* [Daten] Schnelleres Daten-Upgrade nach Veröffentlichung einer neuen Version
* [Content] AI Delighter unter Windows 7 und Windows 8 verfügbar
* [Content] AI Delighter auf RTX-GPU verfügbar

Fest:

* Mögliche Absturz beim Beenden der Anwendung beheben
* Popup-Fenster &quot;Exportieren&quot; wird beim Exportieren großer Sammlungen schneller geöffnet

Bekannte Probleme:

* Die Verwendung mehrerer Delighter in einem Material wird nicht empfohlen.
* Delighter-Absturz mit älteren NVIDIA-Treibern (weniger als 400.x)
* Der schnelle Wechsel der Sichtbarkeit einer Delighter-Bühne wirkt sich auf die Leistung aus
* Absturz beim Laden Ihrer eigenen Umgebung
