# Programmfehler melden

Sie können Fehler in Sampler melden.

Öffnen Sie das Menü <b>Hilfe </b> und wählen Sie dann <b>Fehler melden</b>g:

![](../assets/Bug-report-howto.png.img.png){width="700px"}

Füllen Sie das folgende Formular aus:

![](../assets/Bug-report-window.png.img.png){width="400px"}

Klicke dann auf &quot;Senden&quot;. Die eingegebenen Informationen werden direkt an das Sampler-Entwicklungsteam weitergegeben.
