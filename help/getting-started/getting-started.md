# Erste Schritte

![](../assets/6.0_HomeScreen.png)

Wenn Sie Sampler öffnen, wird der **Startbildschirm** angezeigt. Der **Startbildschirm** bietet verschiedene Optionen, die Ihnen den Einstieg in ein neues oder bestehendes Sampler-Projekt erleichtern.

1. **Neues Projekt**: Erstellen Sie ein neues Projekt, indem Sie eine Datei importieren und aus einer Sammlung von Schnellaktionen auswählen.
1. **Schnellstart**: Erstellen Sie ein neues leeres Projekt.
1. **Öffnen**: Öffnen Sie ein Projekt mit dem Dateibrowser Ihres Systems.
1. **Start**: Greifen Sie auf empfohlene Tutorials zu, erstellen Sie ein neues Projekt oder zeigen Sie eine Liste der aktuellen Projekte an.
1. **Training**: Greifen Sie auf Videotutorials und Lerninhalte für Sampler zu.
1. **Dateien**: Zeigt eine Liste der zuletzt geöffneten Projekte an.
1. **Über Sampler**: Erfahren Sie mehr über Ihre Version von 3D Sampler.
1. **Dokumentation**: Sehen Sie sich die Dokumentation an und erweitern Sie Ihre Fähigkeiten.

Wenn Sie ein neues Projekt öffnen, ein neues Projekt starten oder eine [Schnellaktion](../features-and-workflows/quick-actions.md) verwenden, wird der **Startbildschirm** ausgeblendet, sodass Sie mit dem Erstellen von Elementen beginnen können. Sie können den **Startbildschirm** erneut über das **Dateimenü** öffnen.
