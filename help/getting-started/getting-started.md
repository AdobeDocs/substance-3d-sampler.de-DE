# Erste Schritte

![](../assets/6.0_HomeScreen.png)

Wenn Sie Sampler öffnen, wird der <b>Startbildschirm</b> angezeigt. Der <b>Startbildschirm</b> bietet verschiedene Optionen, die Ihnen den Einstieg in ein neues oder bestehendes Sampler-Projekt erleichtern.

1. <b>Neues Projekt</b>: Erstellen Sie ein neues Projekt, indem Sie eine Datei importieren und aus einer Sammlung von Schnellaktionen auswählen.
1. <b>Schnellstart</b>: Erstellen Sie ein neues leeres Projekt.
1. <b>Öffnen</b>: Öffnen Sie ein Projekt mit dem Dateibrowser Ihres Systems.
1. <b>Start</b>: Greifen Sie auf empfohlene Tutorials zu, erstellen Sie ein neues Projekt oder zeigen Sie eine Liste der aktuellen Projekte an.
1. <b>Training</b>: Greifen Sie auf Videotutorials und Lerninhalte für Sampler zu.
1. <b>Dateien</b>: Zeigt eine Liste der zuletzt geöffneten Projekte an.
1. <b>Über Sampler</b>: Erfahren Sie mehr über Ihre Version von 3D Sampler.
1. <b>Dokumentation</b>: Sehen Sie sich die Dokumentation an und erweitern Sie Ihre Fähigkeiten.

Wenn Sie ein neues Projekt öffnen, ein neues Projekt starten oder eine [Schnellaktion](../features-and-workflows/quick-actions.md) verwenden, wird der <b>Startbildschirm</b> ausgeblendet, sodass Sie mit dem Erstellen von Elementen beginnen können. Sie können den <b>Startbildschirm</b> erneut über das <b>Dateimenü</b> öffnen.
