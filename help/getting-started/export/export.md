# Exportieren

Sie können Ihre Assets exportieren, indem Sie **Exportieren als** im **Dateimenü** oder mit Tastaturbefehl **Strg + E** auswählen. Dadurch wird das [Exportfenster](../../getting-started/export/export-window/export-window.md) geöffnet, in dem Sie Ihren Export anpassen können.

>[!NOTE]
>
> Wenn Sie im **Exportfenster** die Option &quot;Materialmodell&quot; ändern, werden die exportierten Dateinamen entsprechend dem ausgewählten Materialmodell geändert.

![Exportfenster mit ausgewählten Material-Einstellungen](../../assets/6.0_ExportWindowMaterialSettings.png)

Sampler unterstützt die wichtigsten Dateiformate für Ihre Assets:

* Materialien können als **SBS** oder **SBSAR**-Dateien exportiert werden.
* Alternativ können Materialien als Bitmap-Texturen pro Kanal in den folgenden Dateiformaten exportiert werden:
  * **EXR**
  * **JPEG**
  * **PNG**
  * **TARGA**
  * **TIFF**
  * **USDA**
  * **USD**
  * **USDZ**
