# Ressourcen importieren

Sampler kann externe Ressourcen wie Bilder und Substance-Dateien verwenden, um Ihr Projekt zu ändern. Verwenden Sie eine der folgenden Optionen, um eine Datei in Ihr Projekt zu importieren:

* Ziehe die gewünschte Datei per Drag-and-Drop von deinem Explorer in das Sampler-Fenster. Ein Importfenster mit Optionen zum Ändern der Importmethode wird angezeigt.

![](../assets/importing-resources-Importwindow.png)

* Verwenden Sie in der <b>linken Leiste</b> die Schaltfläche <b>Inhalt abrufen </b> und wählen Sie dann entweder <b>In Ebenenstapel importieren</b> oder <b>In Ihre Elemente importieren</b> aus. Beide Optionen öffnen einen Explorer, in dem Sie die zu importierende(n) Datei(en) auswählen können.
  * <b>Importieren in Ebenenstapel</b> importiert die Datei für Ihr aktuelles Projekt.
  * <b>Importieren in Ihre Assets</b> importiert die Datei, sodass von jedem Projekt aus darauf zugegriffen werden kann.

![](../assets/Project_CreateNew.png)

* Wenn im Bedienfeld <b>Ebenen</b> keine Ebenen erstellt wurden, können Sie die verfügbaren Verknüpfungen verwenden, um eine Datei zu importieren, die die Grundlage Ihres Materials bildet.

>[!NOTE]
>
> Ressourcen sind verknüpft und nicht importiert. Wenn eine Ressourcendatei verschoben oder gelöscht wird, wirkt sich dies auf Material oder Inhalte aus, die mit dieser Ressource erstellt wurden. Daher wird empfohlen, einen eigenen Ordner für Sampler Assets zu verwenden.
> 
> Standardmäßig werden die in Sampler enthaltenen Assets unter C:\Program Files\Adobe\Adobe Substance 3D Sampler\Resources\assets gespeichert.

## Unterstützte Dateiformate

| Art | Beschreibung |
| --- | --- |
| <b>Bitmaps/Images</b> (JPEG, PNG usw.) | Sie können Bitmaps per Drag &amp; Drop im Bereich <b>Ebenen </b> oder in SBSAR- oder Filterparameter importieren, die eine Bildeingabe ermöglichen. |
| <b>Substance-Pakete</b> (SBSAR) | Sie können SBSAR-Dateien in das Bedienfeld <b>Elemente </b> oder in das Bedienfeld <b>Ebenen </b> importieren. |
