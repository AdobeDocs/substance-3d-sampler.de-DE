# Projektverwaltung

In Substance 3D Sampler können Sie Sammlungen verwenden, um alle Ihre Assets und Materialien zu verwalten. Projekte sind eine gute Möglichkeit, deine Materialien zu organisieren. Ein Projekt kann exportiert oder importiert werden, um es einfach für andere Computer freizugeben.

## Neues Projekt erstellen

Um ein neues Projekt zu erstellen, wählen Sie <b>Neues Projekt erstellen</b> auf dem <b>Startbildschirm </b> oder <b>Datei > Neues Projekt erstellen</b>. Wenn Sie ein neues Projekt erstellen, wird das Dialogfeld &quot;Schnellstart&quot; geöffnet, in dem Sie eine Schnellaktion auswählen oder eine Bild- oder Substance-Datei importieren können, um Ihr Projekt zu starten.

![](../assets/6.0_HomeScreenFocus.png)

Alternativ können Sie die Schaltfläche <b>Schnellstart</b> verwenden, um direkt in ein leeres Projekt zu springen. Sie können Elemente und Inhalte weiterhin nach Bedarf manuell importieren.

Nach dem Klicken auf die Schaltfläche &quot;Neu erstellen&quot; wird das Projekt automatisch geöffnet und mit dem Namen &quot;*Unbenanntes Projekt\**&quot; versehen, bis Sie Ihr Projekt speichern. Sie können Elemente zu Ihrem Projekt hinzufügen, indem Sie im Projektfenster <b>die <b>Schaltfläche für neue Elemente </b> markieren.</b>

![](../assets/Project_CreateNew_1.png){width="600px"}

## Speichern eines Projekts

Verwenden Sie zum Speichern eines Projekts die Menüaktion &quot;<b>Datei&quot; > &quot;</b>&quot; oder &quot;<b>Speichern unter&quot;</b>&quot;. Daraufhin wird ein Dialogfeld geöffnet, in dem Sie auswählen können, welchen Namen Sie verwenden und wo Sie die Projektdateien speichern möchten.

Alternativ können Sie den Tastaturbefehl <b>Strg + S</b> zu <b>Speichern</b> oder <b>Strg + Umschalt + S</b> zu <b>Speichern unter</b> verwenden.

Gespeicherte Projekte werden als Datei mit dem Namen <b>YourProject.ssa</b> angezeigt. SSA ist ein Sampler-Dateiformat, in dem Informationen über Ihr Projekt und etwaige Abhängigkeiten gespeichert werden.

## Öffnen eines vorhandenen Projekts

Projekte können auf verschiedene Weise geöffnet werden:

* Auf dem <b>Startbildschirm</b>: Verwenden Sie die Liste der zuletzt verwendeten Projekte, um ein Projekt durch Doppelklicken schnell zu öffnen.
* Auf dem <b>Startbildschirm</b>: Klicken Sie auf <b>Öffnen</b>, um einen Dateibrowser zu öffnen, in dem Sie die gewünschte Datei auswählen können.
* Über das Menü **Datei > Projekt öffnen**.
