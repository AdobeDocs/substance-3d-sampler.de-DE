# Projektverwaltung

In Substance 3D Sampler können Sie Sammlungen verwenden, um alle Ihre Assets und Materials zu verwalten. Projekte sind eine gute Möglichkeit, Ihre Materials zu organisieren. Ein Projekt kann exportiert oder importiert werden, um es einfach für andere Computer freizugeben.

## Neues Projekt erstellen

Um ein neues Projekt zu erstellen, wählen Sie **Neues Projekt erstellen** auf dem Bildschirm **Startseite** oder **Datei > Neues Projekt erstellen**. Wenn Sie ein neues Projekt erstellen, wird das Dialogfeld &quot;Schnellstart&quot; geöffnet, in dem Sie eine [Schnellaktion](../features-and-workflows/quick-actions.md) auswählen oder eine Bild- oder Substance-Datei importieren können, um Ihr Projekt zu starten.

>[!TIP]
>
> Wenn Sie Sampler noch nicht kennen, können Ihnen [Schnellaktionen](../features-and-workflows/quick-actions.md) dabei helfen, schnell loszulegen, indem Sie mehr darüber erfahren, was Sampler Ihnen helfen kann.

![](../assets/6.0_HomeScreenFocus.png)

Alternativ können Sie die Schaltfläche **Schnellstart** verwenden, um direkt in ein leeres Projekt zu springen. Sie können Elemente und Inhalte weiterhin nach Bedarf manuell importieren.

Nach dem Klicken auf die Schaltfläche &quot;Neu erstellen&quot; wird das Projekt automatisch geöffnet und mit dem Namen &quot;*Unbenanntes Projekt\**&quot; versehen, bis Sie Ihr Projekt speichern. Sie können Elemente zu Ihrem Projekt hinzufügen, indem Sie im **Projektfenster** die **Schaltfläche &quot;Neues Element&quot;** markieren.

![](../assets/Project_CreateNew_1.png){width="600px"}

## Speichern eines Projekts

Verwenden Sie zum Speichern eines Projekts die Menüaktion **Datei > Speichern** oder **Speichern als**. Daraufhin wird ein Dialogfeld geöffnet, in dem Sie auswählen können, welchen Namen Sie verwenden und wo Sie die Projektdateien speichern möchten.

Alternativ können Sie Tastaturbefehl **Strg + S** bis **Speichern** oder **Strg + Umschalt + S** bis **Speichern unter** verwenden.

Gespeicherte Projekte werden als Datei mit dem Namen **YourProject.ssa** angezeigt. SSA ist ein Sampler-Dateiformat, in dem Informationen über Ihr Projekt und etwaige Abhängigkeiten gespeichert werden.

## Öffnen eines vorhandenen Projekts

Projekte können auf verschiedene Weise geöffnet werden:

* Auf dem **Startbildschirm**: Verwenden Sie die Liste der zuletzt verwendeten Projekte, um ein Projekt durch Doppelklicken schnell zu öffnen.
* Auf dem **Startbildschirm**: Klicken Sie auf **Öffnen**, um einen Dateibrowser zu öffnen, in dem Sie die gewünschte Datei auswählen können.
* Über das Menü **Datei > Projekt öffnen**.
