# Umgebungsvariablen

Auf dieser Seite werden Umgebungsvariablen aufgelistet, die verwendet werden können, um das Standardverhalten der Anwendung zu überschreiben.

| Variable | Beschreibung |
| --- | --- |
| **SUBSTANCE\_SAMPLER\_LICENSE** | Wert: Pfad zur Datei license.keyÜberschreiben Sie den Speicherort, an dem die Anwendung die Lizenzdatei lädt.  **Hinweis:** Versionen vor 3.0 verwenden stattdessen diesen Variablennamen:**SUBSTANCE\_ALCHEMIST\_LICENSE** |
