# Schieberegler

![](../../assets/sliders-basic.gif)

Es gibt eine Option, um einen bis mehrere Regler zu animieren. Drücken Sie **Strg**, wenn Sie mit dem Mauszeiger auf einen Schieberegler zeigen, wird ein **Play**-Symbol angezeigt, um die Animation zu starten.

Sie können die Animation anhalten, indem Sie **Strg** drücken, wenn Sie mit dem Mauszeiger auf einen animierten Schieberegler zeigen, wird ein **Pause**-Symbol angezeigt, um die Animation dieses Schiebereglers zu stoppen.

Wenn Sie alle Schieberegler anhalten möchten, drücken Sie **P**. Drücken Sie zum Neustart erneut **P**.
