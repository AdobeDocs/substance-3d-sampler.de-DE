# Ebenenauflösung

Mit dem System zur Ebenenauflösung hast du die volle Kontrolle über die Auflösung der einzelnen Ebenen im Ebenenstapel. Eine Ebene kann entweder die Auflösung Ihrer Dokumentgröße oder die Auflösung der darunter liegenden Ebene annehmen.

Die Auflösung wird auf jeder Ebene angezeigt, um ganz einfach zu visualisieren, wie die Auflösung Ihres Materials die Arbeit beeinflusst.

Auf diese Weise können Sie die Qualität Ihrer Materialien steigern, aber beachten Sie, dass höhere Auflösungen die Leistung beeinträchtigen können, wenn Sie an Ihren Elementen arbeiten.

![Ebenenbedienfeld und Eigenschaftenbedienfeld mit Ebenenauflösung](../../assets/LayersPanelAndPropertiesPanel.png)

Mit nur einem Klick wechseln Sie von der Arbeitsauflösung zu einer höheren Auflösung, um das fertige Material zu präsentieren, das exportiert werden kann.

![Alle Ebenenauflösung wechseln](../../assets/Switch_All_Resolution.gif)
