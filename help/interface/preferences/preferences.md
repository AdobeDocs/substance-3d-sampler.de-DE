## Allgemein

* **Schnittstelle**
  * **Sprache**\
    Sampler unterstützt derzeit die folgenden Benutzeroberflächensprachen:
    * Amerikanisches Englisch
    * Français
    * Deutsch
    * Japanisch
    * Vereinfachtes Chinesisch
    * Italienisch
    * Spanisch
    * Portugiesisch
* **Projekt**
  * **Normales Format**\
    Legen Sie das normale Format fest, das in der Anwendung verwendet wird.
  * **Standardebenenauflösung**\
    Legen Sie die Standardauflösungsstrategie fest, die in der Anwendung verwendet wird.
  * **Standard-Materialmodell**
    Legen Sie das Standardmodell fest, das verwendet werden soll, wenn ein Material erstellt wird oder Schnellaktionen ein Materialmodell anderweitig auswählen müssen.
  * **Kachelung der Standard-Material-Textur - U**\
    Legen Sie die standardmäßige U-Texturkachelung fest.
  * **Kachelung der Standard-Material-Textur - V**\
    Legen Sie die Standardkachelung für die V-Struktur fest.
  * **Standardmaßstab des Heights**\
    Legen Sie die Standardskalierung für Heights für Materialien fest.
* **Datenschutz**
  * **Automatisches Senden von Nutzungsstatistiken**
    Stellt ein, ob anonymisierte Nutzungsstatistiken gesendet werden sollen, um die Sampler zu verbessern.
* **Farbeinstellungen**
  * **Experimenteller Volltonfarbenwähler**\
    Aktivieren oder deaktivieren Sie den experimentellen Farbwähler überall dort, wo ein Farbauswahlparameter angezeigt wird. Mit dem experimentellen Farbwähler können Sie Farben direkt aus einer Reihe von PANTONE-Farbfeldern auswählen.
* **Ressourcen**
  * **Miniaturansichtsqualität**\
    Passen Sie die Qualität von Miniaturen im Bedienfeld &quot;Elemente&quot; an. Durch die Verringerung der Miniaturansichtqualität können die Ladezeiten von Miniaturansichten verbessert werden.
* **Interoperabilität**
  * **An Designer-Format senden**\
    Legen Sie das Format fest, das die Anwendung an Designer senden soll.
    * **SBS**
    * **SBSAR**
* **Machine Learning**
  * **GPU-beschleunigte neuronale Netzwerke**\
    Aktivieren oder deaktivieren Sie die GPU-beschleunigten neuronalen Netzwerke, um die Leistung der Anwendungen zu verbessern.

### Speicher und Cache

* **Cache**\
  Verwenden Sie diese Einstellungen, um Cache-Speicherorte zu aktualisieren.
  * Pfad des Cacheordners für gerenderte Texturen
  * Pfad für den Zwischenspeicher von Miniaturansichten.
* **Material-Aufnahme**\
  Verwenden Sie diese Einstellung, um den Speicherort des Material-Aufnahmecaches zu aktualisieren.
  * Pfad für den Material-Aufnahmecache.
  * Captis IP-Adresse\
    Verbinden Sie sich mit einem Captis-Gerät in Ihrem lokalen Netzwerk.
  * Verwenden Sie das Captis-Gerät als USB-Speicher für kopierte Dateien.
* **In Projektdateien eingebetteter Cachespeicher**\
  Ändern Sie, wie Sampler zwischengespeicherte Inhalte beim Speichern von Dateien behandelt.

### Plug-ins und Skript

* **Schnittstelle**
  * **Protokollfenster aktivieren**\
    Aktivieren oder Deaktivieren des Protokollbedienfelds. Das Protokollfenster kann von der **[rechten Seitenleiste](../sidebars.md)** aus geöffnet werden, wenn es aktiviert ist.
* **Plug-ins verwalten**
  * Wählen Sie den Speicherort für Plug-ins aus, importieren Sie neue Plug-ins und aktivieren oder deaktivieren Sie vorhandene Plug-ins.
* **Skripte verwalten**
  * Wählen Sie den Speicherort des Skriptordners aus und importieren Sie Skripte.
