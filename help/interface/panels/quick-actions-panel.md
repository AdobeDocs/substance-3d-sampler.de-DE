# Bedienfeld für Schnellaktionen

![](../../assets/quickactionpanel.png)

[Schnellaktionen](../../features-and-workflows/quick-actions.md) sind eine Sammlung von Features und Workflows, mit denen Sie leistungsstarke Aktionen mit nur wenigen Klicks ausführen können. Verwenden Sie Schnellaktionen, um ein Material zu erstellen, ein Projekt zu erstellen oder die Ebenen, die Sie benötigen, zu Ihrem vorhandenen Stapel hinzuzufügen.

Klicken Sie im Bedienfeld für den Schnellzugriff auf eine Schnellaktion, um sie dem Stapel hinzuzufügen oder je nach Schnellaktionstyp ein neues Element zu erstellen. Schnellaktionen sind in die folgenden Kategorien unterteilt:

* **Zuletzt verwendet**: Greifen Sie auf Ihre zuletzt verwendeten Schnellaktionen zu.
* **Arbeiten an Bildern**: Bilder importieren, konvertieren oder anpassen.
* **Materialscan verbessern**: Richten Sie ein gescanntes Material aus, verfeinern oder kacheln Sie es, um bessere Ergebnisse zu erzielen.
* **Material aus Bildern erstellen**: Fügen Sie die erforderlichen Ebenen zu Ihrem Ebenenstapel hinzu, um ein oder mehrere Bilder in ein Material zu konvertieren.
* **Ein Material von Grund auf neu erstellen**: Erstelle ein neues Material-Asset - mit den ersten Ebenen.

Wenn Sie den Mauszeiger über eine Schnellaktion bewegen, können Sie die Optionsschaltfläche verwenden, die wie folgt angezeigt wird:

* **Wenden Sie die Schnellaktion** auf den Ebenenstapel an.
* **Einrichten** der Schnellaktion über Dialogfelder.
* **Erstellen Sie ein neues Asset** mithilfe der ausgewählten Schnellaktion.
* **Erstellen Sie ein neues Projekt** mithilfe der ausgewählten Schnellaktion.
