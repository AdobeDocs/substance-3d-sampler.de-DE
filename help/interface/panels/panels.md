# Fenster

Jedes Bedienfeld in Sampler ist einem bestimmten Zweck gewidmet. Standardmäßig sind nur die folgenden vier Fenster geöffnet:

* **Projektfenster**: Ermöglicht Ihnen die Verwaltung von Assets im aktuell geöffneten Projekt.
* **Bedienfeld &quot;Elemente&quot;**: Enthält Starter-Inhalte und andere Elementbibliotheken, die Sie beim Erstellen Ihrer Elemente verwenden können.
* **Ebenenbedienfeld**: Zeigt den Ebenenstapel des ausgewählten Elements an.
* **Eigenschaftenbereich**: Zeigt die Eigenschaften und Parameter für die aktuell ausgewählte Ebene an - die **Ebenen** und **Eigenschaftenfenster** werden zusammen verwendet

Diese Bedienfelder werden am häufigsten bei der Erstellung von Elementen verwendet.

Die verbleibenden Bedienfelder sind standardmäßig geschlossen und enthalten Optionen und Steuerelemente, die in der Regel nicht regelmäßig geändert werden müssen. Sie können von der linken und rechten Seitenleiste aus auf diese Bedienfelder zugreifen.

Sie können über die **linke Seitenleiste** auf das Bedienfeld für Schnellaktionen **zugreifen.**.

Der Bereich &quot;**Kanaleinstellungen**&quot; ist standardmäßig am unteren Rand der **linken Seitenleiste** verfügbar.

</td>
<td style="border: 0;" valign="top">

Die folgenden Fenster werden standardmäßig oben in der **rechten Seitenleiste** gespeichert:

* **Bedienfeld „Veröffentlichte Parameter“**: Ermöglicht Ihnen die Verwaltung der Parameter, die verfügbar sind, wenn Ihr Asset als SBSAR- oder SBS exportiert wird.
* **Bedienfeld &quot;Physische Größe&quot;**: Konfigurieren Sie die reale Physische Größe Ihrer gescannten Proben und Bilder.
* **Metadatenbedienfeld**: Bearbeiten Sie Metadaten, indem Sie eine Beschreibung hinzufügen oder den Namen des Autors für das ausgewählte Element ändern.
* **Exportierenbedienfeld**: Senden Sie Ihr Element direkt an andere Anwendungen oder exportieren Sie es zur allgemeinen Verwendung.

</td>
</tr>
</table>

Sie können den Arbeitsbereich anpassen, indem Sie Bedienfelder verschieben - [Weitere Informationen finden Sie auf der Seite der Benutzeroberfläche](../../interface/interface.md).

Um jederzeit zum Standardarbeitsbereichlayout zurückzukehren, verwenden Sie **Fenster > Auf Standardlayout zurücksetzen**.
