# Shader-Einstellungsbedienfeld

![](../../assets/Shader-settings-panel-gen.png.img.png)

Im <b>Bedienfeld &quot;Shader-Einstellungen&quot;</b> können Sie konfigurieren, wie der Shader Ihre Elemente auf dem Mesh im 3D-Viewport rendert.

## Materialparameter

Mit den Material-Parametern können Sie anpassen, wie das aktuelle Material vom Shader gerendert wird.

| Parametername | Beschreibung |
| --- | --- |
| Normal-Intensität | Passen Sie die Stärke oder Intensität des Normalen-Map an. |
| Normale und Höhe kombinieren | Stellt ein, ob Height und Normalen-Map in einer einzigen Map kombiniert werden. |
| Height-Grundniveau | Ändern Sie die Basisebene des Heights für Versatz. |
| Emission-Intensität | Passen Sie die Stärke von emissive Maps an. |
| Streuung unter der Oberfläche | Schalten Sie die Volumenstreuung ein oder aus. |
| Brechungsindex | Passen Sie den Winkel an, in dem Licht von Oberflächen abbricht. |
| Coat-Brechungsindex | Passen Sie den Winkel an, in dem das Licht die Oberflächenschicht abbricht. |
| Coat-Normal-Intensität | Passen Sie den normalen Maßstab speziell für die Oberflächenbeschichtung an. |
