# Bedienfeld „Veröffentlichte Parameter“

![](../../assets/ezgif-com-gif-maker-7.gif)

Die **Bedienfeld „Veröffentlichte Parameter“** enthält die Parameter, die im Bereich **Eigenschaften verfügbar gemacht wurden.**

Die farbigen Punkte dienen der Visualisierung, mit welcher Ebene der Parameter verbunden ist. Leere Punkte zeigen an, dass der Parameter von einer Überblendungsebene stammt.

![](../../assets/ezgif-com-gif-maker-1.gif)

Es gibt mehrere Möglichkeiten, mit den exponierten Parametern zu interagieren:

| Aktionen | Anleitung |
| --- | --- |
| Unverfügbar machen eines Parameters | Klicken Sie mit der rechten Maustaste auf einen Parameter und wählen Sie &quot;Unexpose&quot; aus. |
| Bearbeiten der Beschriftung eines Parameters | Klicken Sie mit der rechten Maustaste auf einen Parameter und wählen Sie &quot;Bearbeiten&quot;, geben Sie die neue Bezeichnung ein. |

Sie können mit allen Parametern wie gewohnt mit dem **Eigenschaftenfenster interagieren.** Die Änderungen werden im 3D-Viewport widergespiegelt.
