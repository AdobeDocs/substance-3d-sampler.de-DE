# Horizont begradigen

## Beschreibung

Begradigen Sie den Horizont, indem Sie Ihre Umgebung in der **2D-Ansicht** verzerren.

</td>
</tr>
</table>

## Parameter

**Basisparameter**

* **Horizontkorrektur aktivieren**: Knebel\
  Stellt ein, ob der korrigierte Horizont oder eine Linie mit der resultierenden Horizontlinie angezeigt werden soll. Deaktivieren Sie diese Option, und passen Sie die Handles in der **2D-Ansicht** an, um besser zu verstehen, wie dieses Tool die Umgebung verzerrt, um den Horizont anzupassen.
* **Horizontale Drehung**: 0-1\
  Drehen Sie die Umgebung. Die Ergebnisse dieses Parameters sind nur sichtbar, wenn **Horizontkorrektur aktivieren** aktiviert ist.
