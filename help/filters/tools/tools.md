# Werkzeuge

Werkzeuge sind die umfangreichsten Filter in Sampler. Daher ist es mitunter schwierig, die Merkmale dieser Werkzeuge zu verstehen. Der einfachste Weg, um Werkzeugfilter zu verstehen, ist, dass sie verwendet werden, um technische Probleme mit Materialien zu beheben.

Viele Tools können für Bilder und Materialien verwendet werden. Im Allgemeinen empfiehlt es sich, ein Bild mit Filtern zu korrigieren, bevor du es in ein Element umwandelst. Indem man das Bild zuerst korrigiert, müssen die Tools nur auf einem Ein Kanal arbeiten - die Bilddaten, während das Korrigieren des Materials das Korrigieren mehrerer Kanäle erfordert. Nur das Korrigieren eines Ein Kanal verringert den Verarbeitungsaufwand, aber auch das Fehlerpotenzial.

Werkzeugfilter nutzen häufig Handles und andere Steuerelemente in der **2D-Ansicht**. Daher empfiehlt es sich oft, die **2D-Ansicht** beim Arbeiten mit Tools sichtbar zu machen.
