# Filter

>[!IMPORTANT]
>
> Die Unterstützung für Umgebungslicht und Mesh wird mit der Veröffentlichung von Sampler 5.2 entfernt. Zum Entfernen von Umgebungslichtern gehört auch das Entfernen von HDRI-Werkzeugen und Filtern.

In Adobe Substance 3D Sampler sind Filter das primäre Tool, das zum Ändern und Anpassen von Elementen verwendet wird. Sampler umfasst die folgenden Filtertypen:

* [Generatoren](../filters/generators/generators.md) - fügen Sie Ihrem Material neue Elemente hinzu.
* [Anpassungen](../filters/adjustments/adjustments.md) - Passen Sie die Werte der Kanäle Ihres Materials an.
* [Tools](../filters/tools/tools.md) - Suchen und Beheben technischer Probleme.
* [HDRI-Werkzeuge](../filters/hdri-tools/hdri-tools.md) - Filter, die spezifisch für Umgebungslichter sind.
* [Tragen und fertigstellen](../filters/wear-and-finish/wear-and-finish.md) - ändern Sie das Aussehen und das Gefühl Ihres Materials.

Es ist möglich, eigene Filter mit Adobe Substance 3D Designer zu erstellen -[klicken Sie hier, um herauszufinden, wie das geht](custom-filters.md).

Filter können auf verschiedenen Technologien basieren:

* Verfahrensfilter mit Substance Designer
* Bildverarbeitungsfilter, die direkt in C++ und/oder unter Verwendung von künstlicher Intelligenz hergestellt wurden

Die meisten Filter können auf Materialien oder Bilder angewendet werden. Einige Filter haben spezifische Anforderungen in Bezug auf die Kanaleinrichtung. Wenn ein Filter nicht wie erwartet funktioniert, suchen Sie in der Dokumentation nach ihm, um einen Benutzerhandbuch anzuzeigen.
