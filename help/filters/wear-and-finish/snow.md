## Parameter

**Basisparameter**

* **Zufallsparameter**:\
  Der Zufallswert bestimmt die Zufallswerte anderer Parameter, die den Zufallswert in diesem Filter verwenden.
* **Neuer Snow**: 0-1\
  Ändere die Schneemenge.
* **geschmolzener Snow**: 0-1\
  Kontrollieren Sie die Menge des geschmolzenen Schnees. Dieser Parameter ist sehr empfindlich.
* **Build**: 0-1\
  Passen Sie an, wie viel Schnee sich im Laufe der Zeit aufgebaut hat. Dadurch werden die zugrunde liegenden Height-Details verdeckt.
* **Smoothness**: 0-1\
  Lege fest, wie weich der Schnee erscheint. Dadurch werden die Details des Heights beim Erhöhen unkenntlich gemacht. Schnee kann weicher und tiefer erscheinen.
* **Flakes-Intensität**: 0-1\
  Passen Sie die Sichtbarkeit einzelner Schneeflocken an.
* **Benutzerdefinierte Maske verwenden**: Knebel\
  Aktivieren oder Deaktivieren der Verwendung einer benutzerdefinierten Maske. Wenn aktiviert, werden die folgenden Parameter angezeigt:
  * **Benutzerdefinierte Maske**: Bild/Pinsel\
    Wählen Sie ein Bild aus, das als Maske verwendet werden soll, oder malen Sie mit dem Pinsel eine benutzerdefinierte Maske direkt in der 2D-Ansicht.
  * **Maske weichzeichnen**: 0-1\
    Die Maske weichzeichnen.
  * **Maskenintensität**: 0-1\
    Passe die Deckkraft der Maske an.
