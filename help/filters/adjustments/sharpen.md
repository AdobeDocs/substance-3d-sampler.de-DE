## Beschreibung

Mit dem Scharfzeichnungsfilter können Sie die Details in einem bestimmten Kanal scharfzeichnen.

Hinweis: Der Scharfzeichnungsfilter ist zwar hervorragend zum schnellen Hinzufügen von Details geeignet, kann aber leicht zu übermäßig verwendet werden, um einen Kanal lauter und Details übertönend erscheinen zu lassen. Suche nach einer guten Balance.

## Parameter

**Vorgaben**

Verwenden Sie Vorgaben, um schnell die Parameter zu ändern und verschiedene Parkettböden anzuzeigen.

**Basisparameter**

* **Kanalauswahl**:\
  Wählen Sie den Kanal aus, auf den der Scharfzeichner angewendet werden soll.
* **Scharfzeichnen**: 0-3\
  Passen Sie die Intensität des Scharfzeichnungseffekts an.

**Maske**

* **Benutzerdefinierte Maske verwenden**: Knebel\
  Aktivieren oder Deaktivieren der Verwendung einer benutzerdefinierten Maske. Wenn aktiviert, werden die folgenden Parameter angezeigt:
  * **Maske**: Bild/Pinsel\
    Wählen Sie ein Bild aus, das als Maske verwendet werden soll, oder verwenden Sie den Pinsel, um eine benutzerdefinierte Maske direkt in die 2D-Ansicht Malen
  * **Benutzerdefinierte Maske - Weichzeichnen**: 0-1\
    Weichzeichnen der Maske
  * **Benutzerdefinierte Maske - Umkehren**: Knebel\
    Maske umkehren.
