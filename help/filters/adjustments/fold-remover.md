## Parameter

<b>Basisparameter</b>

* <b>Eingabetabelle</b>: Umschalten\
  Aktivieren Sie diese Einstellung, um sicherzustellen, dass dieser Filter Kachelmaterialien nicht beschädigt.
* <b>Radius</b>: 0-50\
  Passen Sie den Radius an, um die Größe der Falten zu steuern, die der Filter zu minimieren versucht. Bei einem niedrigen Radius werden feinere Details geglättet.
* <b>Lokale Details</b>: 0-1\
  Verwenden Sie einen höheren Wert, um lokale Details beizubehalten und gleichzeitig Ordner zu entfernen.

<b>Normal</b>

* <b>Gemeinsame Parameter überschreiben</b>: Umschalten\
  Steuern Sie die Parameter für diesen Kanal einzeln.

<b>Height</b>

* <b>Gemeinsame Parameter überschreiben</b>: Umschalten\
  Steuern Sie die Parameter für diesen Kanal einzeln.

<b>Maske</b>

* <b>Benutzerdefinierte Maske </b>: Umschalten\
  Aktivieren Sie die Verwendung einer benutzerdefinierten Maske, um zu steuern, wo die Effekte dieses Filters angezeigt werden.
* <b>Benutzerdefinierte Maske </b>: Pinsel-/Bildauswahl\
  Erstellen oder wählen Sie eine benutzerdefinierte Maske aus.
* <b>Benutzerdefinierte Maskeninvertierung</b>: Umschalten\
  Kehre die Maske um.
