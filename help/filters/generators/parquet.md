## Parameter

**Vorgaben**

Verwenden Sie Vorgaben, um schnell die Parameter zu ändern und verschiedene Parkettböden anzuzeigen.

**Basisparameter**

* **Zufallsparameter**:\
  Der Zufallswert bestimmt die Zufallswerte anderer Parameter, die den Zufallswert in diesem Filter verwenden.
* **Mustertyp**:\
  Parkettmuster auswählen
* **X Betrag**: 1-30\
  Ändern der Anzahl der Planken auf der X-Achse
* **Y Betrag**: 1-30\
  Ändern der Anzahl der Planken auf der Y-Achse
* **Nahtabstand**: 0-1\
  Ändern Sie den Abstand der Abschrägung um die Nähte der Bretter
* **Planks-Variation**: 0-1\
  Farbe und Raueit jeder Planke automatisch variieren

**Erweitert**

* **Offset für englische Muster**: 0-1 (Dieser Parameter ist nur verfügbar, wenn **Grundlegende Parameter > Mustertyp** auf **Englisch** festgelegt ist.)\
  Versatz jeder Reihe von Dielen gegenüber der vorherigen Reihe ändern
* **Nahtintensität**: 0-1\
  Passen Sie die Normalen der Nähte zwischen den Brettern an, damit sie mehr oder weniger auffällig sind.
* **Kurve der abgeflachten Naht**: 0-1\
  Breite der abgeflachten Kante zwischen den Brettern ändern
* **Naht-Height-Bereich**: 0-1\
  Height der Nahtstellen anpassen.
* **Normale Drehungsvariation der Planks**: 0-1\
  Variieren Sie den Winkel jeder Planke um einen zufälligen Betrag
* **Planks-Raueitsschwankung**: 0-1\
  Variieren Sie die Rauhigkeit jeder Planke beliebig.
